**Total:** ~37 h.

**Gate pass criteria (decided by evaluator):** ≥ 85/100 on the 14-day rubric, zero critical safety violations, all mutants fail as expected, reproducible commands and seeds, operator can explain the code without assistance.

**Stop / reduce-scope triggers:**
- Fewer than SIM-E01, SIM-R01, SIM-C02 passing by Day 14 → extend by one week, cut snapshots from v1.
- Operator cannot explain a failing seed's trace → stop feature work until they can.

## 2. Twenty-four-week plan

Hours per week: 15–20. Each phase ends at a gate. Correctness gates block later phases.

| Weeks | Phase | Deliverables | Depends on | Gate / acceptance |
